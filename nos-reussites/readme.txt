Activités en autonomie sur téléphone pour élèves allophones (UPE2A NSA, LP Victor Laloux, Tours).

== Description ==
L'élève ouvre la page de l'activité et tape son prénom. Le prénom décide du parcours.
Les réponses sont enregistrées au fil de l'eau ; l'enseignant les voit dans Nos réussites > Résultats.

== Installation ==
1. Extensions > Ajouter > Téléverser une extension : choisir le fichier zip, installer, activer.
2. Nos réussites > Élèves : un prénom par ligne dans chaque parcours, puis Enregistrer.
3. Envoyer aux élèves le lien de la page « Activité 10 » (affiché dans Nos réussites > Élèves).

== Ajouter une activité ==
Déposer un fichier activites/activite-NN.json sur le modèle d'activite-10.json, puis créer sa page depuis Nos réussites > Élèves.
